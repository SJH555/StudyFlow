# StudyFlow

StudyFlow 是一款面向 Windows 和 Linux 的桌面学习管理应用，帮助你安排每天的学习、记录投入的时间，并回顾计划与实际之间的差距。

从一份日常计划开始，把学习过程、阶段目标和复盘记录放在一起，让每天的投入有迹可循。

## 安排学习，也记录实际

为不同科目或学习项目建立计划，安排学习时段与休息时间，在“今日计划”中查看当天的安排。开始学习后，用计时记录投入，通过暂停、继续和休息提醒调整节奏。

忘记开计时也可以补充学习记录。计时与手动记录会标明来源，方便回看；补充记录时会检查时间重叠，减少重复统计。

## 从记录中看见变化

学习统计支持按日、周、月查看计划与实际时长，比较不同学习项目的投入，观察完成率和学习趋势。

除了“学了多久”，也可以关注“为什么没有完成”：通过进度追因设置检查时间和完成要求，记录未达目标的原因，并回顾历史总结。

统计页面可导出 HTML 报告，方便离线查看、留存或分享。

## 给近期学习一个方向

在“学情追踪”中设置阶段目标、截止日期和备注，按截止时间或创建时间整理目标。完成一段学习后进行验收，记录目标是否达成，回看已验收目标。

日常计划负责今天做什么，阶段目标帮助你记住这段时间要走到哪里。

## 留意时间都去了哪里

活动提醒会按设置的时间间隔邀请你记录当下在做什么，也可以随时手动“记录此刻”。积累下来的活动记录，让你回顾一天中学习与其他活动的分布。

提醒可选择跳过休息时段，活动记录也支持导出 HTML 报告。

## 融入桌面的学习工具

- **学习提醒**：计划开始和休息结束时，通过铃声、系统通知与弹窗提示。
- **桌面计时**：通过可拖动的悬浮倒计时查看剩余时间。
- **托盘与启动设置**：按习惯设置开机启动、启动时显示方式和关闭窗口后的行为。
- **清晰的界面**：浅色主题，支持调整侧边导航宽度，兼顾日常查看与操作。

## 数据留在本地

学习记录与设置保存在本地，可选择数据存放目录，并开启自动备份。

新版本需要适配本地数据格式时，应用会先征求确认并自动备份，再进行升级；升级完成后直接进入应用。遇到无法识别或当前应用不支持的数据版本时，会阻止继续打开并给出提示。

更换设备或整理数据前，建议保留完整的数据目录与备份。

## 开始使用

在 Windows 或 Linux 上运行对应版本的 StudyFlow 后：

1. 添加学习项目，例如高等数学、英语或一门正在学习的课程。
2. 建立学习计划，安排时段与休息时间。
3. 从今日计划开始学习，或补充已经完成的学习记录。
4. 查看统计、验收阶段目标，逐步调整适合自己的学习节奏。

学习统计中的历史计划时长会受当前计划设置影响；调整计划后，历史计划对比也可能变化。实际学习记录仍可用于回顾自己的投入。
