# 暂停时的两层时间展示

今日页未开始/已结束或暂停时，上方显示完整计划学习时长（沿用原定义，扣除计划休息时长），下方显示持续倒数的剩余时间。仅在正在学习时，显示单独的剩余倒计时。剩余提示从 11px 调为 13px，字重 500，增加 6px 上边距并稍微加深颜色；实测与大数字间距为 8px。

WSL 完成 Vue 类型检查、生产构建和 Windows amd64 构建，版本为 0.5.0-3。既有倒计时逻辑回归脚本 `node scripts/qa/test-countdown.cjs` 通过。

Windows 使用桌面 `studyflow/countdown-layout-qa-0.5.0-3` 隔离合成数据，实际运行桌面 WebView，通过临时 Go overlay 开启本地调试并使用独立的 WebView 路径及单实例标识。此设置仅用于测试程序，交付程序没有这些设置。原 0.5.0-2 便携程序 PID 17968 及其数据没有关闭或修改。

最终界面验证：

- 未开始：计划学习 20:00，下方剩余 12:42。
- 开始：仅显示剩余时间 12:41。
- 暂停：上方保持计划学习 20:00，下方从剩余 12:40 倒数至 12:38。
- 继续：恢复单独剩余倒计时 12:37。

`windows-results.json` 和四张截图记录上述结果。交付文件为桌面 `studyflow/StudyFlow-0.5.0-3-portable/StudyFlow.exe`。
