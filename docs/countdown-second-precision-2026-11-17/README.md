# 今日计划倒计时秒级对齐

倒计时始终以本次计划的结束时刻为边界，不再把剩余时长取整成分钟。暂停只停止累计实际学习时长，距离计划结束的倒计时继续。结束学习后，当前计划即使已有学习记录也恢复显示剩余时间。

复用原有每秒更新的公共时间，没有增加周期定时器或每秒后端请求。会话结束边界缓存为时间戳；每秒计算使用公共时间与该时间戳的差。完整剩余秒数统一向下取整，避免向上取整与一秒采样间隔叠加。开始/暂停/继续后的会话刷新、结束学习、窗口重新获得焦点与页面重新可见时主动更新公共时间。
