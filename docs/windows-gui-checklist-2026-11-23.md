# Windows 原生 GUI 验收清单（2026-11-23）

范围：`77049fc` 之后的新改动。以下均为待测项；Linux 截图、Go 测试和前端类型检查不代表 Windows GUI 验收通过。

## 准备

- [ ] 用 Windows 原生桌面运行待提交代码构建的测试程序，不递增版本号，不覆盖日常安装和工作库。准备独立的全新库、受支持的旧库、当前版本库，以及超新版本、未知结构和损坏库夹具。
- [ ] 默认使用北京时间。切换时区、模拟跨自然日、故障注入和永久重置只在隔离虚拟机或测试目录执行。记录构建标识、Windows 版本、缩放比例、通过/失败和截图。

## P0：启动、升级和恢复

- [ ] **正常启动**：全新库和版本 2 库不要求升级确认，能进入工作区；已有设置选择驻留托盘时，核对从托盘唤回窗口。
- [ ] **旧库升级**：先点「暂时退出」，确认重开仍提示升级；再点「确认继续」，观察升级中状态，成功后自动进入工作区。核对升级前备份、原学习记录和设置保留，再启动不重复弹窗。
- [ ] **启动阻断**：用超新版本、未知结构、损坏库分别检查「请先更新 StudyFlow」「需要检查学习数据」「暂时无法打开学习数据」。能查看错误详情、退出，且不会进入业务页或把原库替换为空库。
- [ ] **时区门禁**：在隔离 Windows 环境切换到非北京时间，确认启动阻断并显示当前和受支持的时区；切回北京时间重开后恢复正常。无法读取系统时区的页面仅用测试构建触发，不修改正式系统的注册表内容来制造故障。
- [ ] **启动页外观**：检查准备、升级确认、升级中、3 种数据库阻断、2 种时区阻断。所有启动卡片保留「StudyFlow」旁的 App 图标，不出现主标题上方单独的状态图标或转圈；升级按钮本身仍可显示加载状态。检查 Windows 标题栏、窗口缩放和长路径换行。
- [ ] **备份预览和恢复**：通过真实 Windows 文件对话框导出、打开并取消一次，然后确认恢复一次。夹具包含正常记录和软删除记录：预览数量只计正常记录；恢复后可见结果正确，独立核对恢复库仍保留软删除行。核对源备份不变、恢复后重启能进入工作区。
- [ ] **计时期间的数据迁移保护**：本机有进行中或暂停计时时，确认整库导出与恢复被拦截并给出提示；结束后可继续。

## P1：学习计划、项目和计时

- [ ] **次日生效**：创建学习项目后当天能补录；新建、编辑、停用、恢复或删除循环计划，以及编辑或停用学习项目，不立即改写今日安排。核对「明日生效／明日起变更／停用／删除」文案，以及次日实际切换；关闭重开后待变更信息仍在。
- [ ] **目录、版本和冲突**：核对计划和项目的启用／停用分组、计数、项目筛选及关联计划；撤销尚未生效的停用后，状态恢复。查看版本历史，检查旧版内容未被覆盖。重叠排程和跨午夜计划仍拒绝保存。
- [ ] **计时与休息**：启动一条计划，检查暂停、休息倒计时、休息到期提醒、继续和结束。期间安排下一版计划，核对运行中计时保留启动时的结束边界和休息额度。用测试库验证重开后的状态，以及不足 10 分钟不进入学习统计。
- [ ] **指定日期补录**：分别选昨天、今天和未来日期。下拉选项按该日项目状态更新；例如项目次日停用，当天可选、次日不可选。检查日期来回切换不会串项目，非法时段或不足 10 分钟不能保存，保存成功后归到所选日期并显示补录来源。

## P1：统计、追因和活动

- [ ] **统计与 HTML 导出**：切换日、周、月，核对完整计划历史、只剩旧复盘目标、历史未知三种数据。旧目标不显示成具体时段，未知不显示成零计划。检查计划与实际的时间、来源标签、图表和导出的 HTML 内容一致。
- [ ] **追因规则与历史**：在旧标准下生成历史结论后，修改阈值或模式，确认过去的结论不按新标准重算；历史能区分达标和已提交追因。测试单条和批量原因提交。
- [ ] **追因关闭再开启**：先生成一条待填记录，关闭后不提示；重新开启并达到检查时间后，原待办重新出现且能提交。停用期间未检查的日期不补算。
- [ ] **活动记录防重复**：通过「记录此刻」和定时提醒弹窗各测一次。在请求尚未返回时连点保存、连按 Enter、点击后立即按 Enter，最终每次操作只增加一条记录。测试构建模拟一次明确保存失败，确认草稿仍在，按钮恢复后可重试。

## 验收边界

- 已决定暂缓的三项不作为本轮失败条件：补录与计时重复累计、非今日补录缺少删除入口、追因历史仅返回最近 120 条。见 [已知问题](known-issues.md)。
- 升级／恢复中强制结束进程、磁盘写满等故障注入不混入上述日常 GUI 主流程；如做发布级验收，另按 [数据库升级维护](database-upgrade-maintenance.md) 的中断／恢复专项执行。
