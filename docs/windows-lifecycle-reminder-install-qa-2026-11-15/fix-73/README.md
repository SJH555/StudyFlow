# Windows 卸载保留数据修复：0.4.0-73

## 范围

用户确认：保留开始菜单快捷方式；卸载时保留数据库、备份、用户文件及数据目录指向；删除程序文件和窗口状态；不处理自定义安装目录记忆；不影响 Linux。

唯一运行行为修改为 build/windows/nsis/project.nsi 的 Windows NSIS 卸载段：去掉安装目录和共用 WebView 目录的递归删除，只 Delete 程序 exe、window-state.json，由原有宏删除卸载程序和卸载注册信息，清理快捷方式，最后非递归删除空安装目录。保留日志、音频缓存和其他未知文件，避免误删用户数据。

开始菜单入口的创建逻辑、数据库访问、数据迁移、开机启动、Linux 安装/卸载脚本没有修改。按仓库打包规则将构建号 72 递增到 73，同步共用版本标签、前端包版本和 Windows 元数据。这些版本元数据更新不改变 Linux 操作逻辑；Linux nfpm 文件在打包后恢复为本轮开始前的原始字节。

## 构建与验证

构建在 WSL Debian 执行既有 wails3 task package GOOS=windows ARCH=amd64。Windows 只运行安装包、卸载程序和 GUI，不安装开发工具，不修改执行策略或系统安全设置。测试全部使用桌面 studyflow/uninstall-fix-qa-73 隔离数据。

1. 旧 72 安装包安装至隔离目录，再升级到 73。exe 与正式 73 便携版哈希一致；注册版本为 0.4.0-73；数据库、真实 SQLite 备份、用户文件、未知根文件和目录记录哈希不变。
2. 卸载 73：上述文件全部保留且哈希不变；程序、卸载器、window-state.json、快捷方式和卸载注册信息删除。
3. 重新安装至同一目录：保留数据没有被安装覆盖，数据库和备份 integrity_check=ok，测试项目和音量设置存在。
4. 外部目录（中文、空格、#、%）：卸载后外部数据库、备份、用户文件完整，安装目录内的 storage-location.txt 及未知用户文件也保留；重装后不覆盖。
5. 实际启动重装版 GUI：可见 QA-uninstall-73 项目，常规设置显示音量 37、版本 v0.4.0-73；数据与备份页仍指向原“外部数据 #100%”目录。退出后再次卸载，验证保留内容相对退出后的快照不变。
6. 无用户数据的全新安装：卸载后空安装目录正确删除。
7. 前五阶段测试原 71 便携版保持运行，PID 16396 未受影响，共用 WebView 目录未删除。GUI 独立启动验证前正常关闭原版，测试后恢复原版运行；临时关闭设置已恢复，真实数据库完整 SQL dump 与本轮安全快照一致。
8. 修改前后逐文件 SHA256 对比：build/linux 全目录及现有 Go 源码共 173 个文件字节一致。没有修改共享 Go 代码，没有重建 Linux 安装包。本次未重复运行 Linux 运行链路测试。

自动化复验脚本为 scripts/qa/test-windows-uninstall.ps1。运行时复制到 Windows 本地 QA 目录，遵守现有执行策略；测试固定限于该隔离目录。不同阶段的结果及 GUI 文本归档在 evidence/。

原测试证据保留历史失败结论，本修复以本目录验证为准。本轮没有修复既有日志或音频测试脚本问题，没有把既有整套测试声称为全绿。
